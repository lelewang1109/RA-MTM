## 0 记号与假设

一个时刻的合并树 T，叶子为 1, …, n。T 的**分支结点**指至少有两个孩子的结点；一元链已收缩。非根分支结点 v 的父结点记为 p(v)，其叶集记为 S_v。

**join tree 约定**：沿指向根的路径，结点值 f 严格递增。叶子是极小值，叶子 i 的值为 f(i)。split tree 对 f 取负号，结论相同。

**并列与平台约定**：
- 假设临界值互不相同（模拟简单性）；
- 二叉化多重鞍点产生的零高度结点（γ = 0）一律收缩，不作为必须连续的子树；
- 单叶帧定义 d_top = 0。

叶子 i 的参数：
- 参考值 q_i ∈ ℝ；
- 宽度 w_i > 0；
- 偏心半径 h_i = ρ·w_i/2，其中 ρ ∈ [0, 1]；
- 最小间距 g ≥ 0；
- 画布 [a, a + L]。

**布局**是三元组 (π, z, u)：π 为叶序，z_i 为区间中心，u_i 为 anchor。约束为：
- (D) 分离：沿 π 相邻的 x、y 满足 z_y − z_x ≥ (w_x + w_y)/2 + g；
- (C) 画布：a + w_i/2 ≤ z_i ≤ a + L − w_i/2；
- (E) 偏心：|u_i − z_i| ≤ h_i。

由 (C)(E) 与 h_i ≤ w_i/2 可得 u_i ∈ [a, a + L]。

定义：
- **Π(T)**：所有使每个结点 v 的叶集 S_v 在 π 中连续的叶序；
- **τ(π)** = min_{z, u 满足 (D)(C)(E)} max_i |u_i − q_i|；
- **τ\*(T)** = min_{π ∈ Π(T)} τ(π)；
- **τ_free** = min_{π ∈ S_n} τ(π)，即允许任意排列。

## 1 固定叶序的精确解

**引理 1（消去 anchor）。** 对固定的 z，有
min_u max_i |u_i − q_i| = max_i max(0, |z_i − q_i| − h_i)。
因此对任意 τ ≥ 0，存在 u 使 max_i |u_i − q_i| ≤ τ，当且仅当 |z_i − q_i| ≤ τ + h_i 对所有 i 成立。

*证明.* 约束 (E) 对各叶子相互独立，每个 u_i 只出现在第 i 项中，所以最小化可以逐项进行。min_{u ∈ [z_i − h_i, z_i + h_i]} |u − q_i| 就是点 q_i 到该区间的距离，即 max(0, |z_i − q_i| − h_i)。取各项最大值即得。□

**引理 2（带盒约束的链的可行性）。** 给定区间 [ℓ_k, r_k]（k = 1, …, n）与 s_k ≥ 0，记 S_{ij} = Σ_{k=i}^{j−1} s_k（S_ii = 0）。存在 z 满足 z_k ∈ [ℓ_k, r_k] 且 z_{k+1} − z_k ≥ s_k，当且仅当对所有 i ≤ j 有 ℓ_i + S_{ij} ≤ r_j。

*证明.*
(⇒) 由链式约束，z_j ≥ z_i + S_{ij} ≥ ℓ_i + S_{ij}；又 z_j ≤ r_j。
(⇐) 令 z_j := max_{i≤j}(ℓ_i + S_{ij})（"最早放置"）。
- 取 i = j 得 z_j ≥ ℓ_j；由条件得 z_j ≤ r_j。
- z_{j+1} ≥ max_{i≤j}(ℓ_i + S_{i,j+1}) = z_j + s_j。□

**命题 1（固定叶序的闭式解）。** 沿 π 重新编号为 1, …, n，令 s_k = (w_k + w_{k+1})/2 + g，
- D_k = Σ_{m<k} w_m + w_k/2 + (k−1)·g，
- E_k = Σ_{m>k} w_m + w_k/2 + (n−k)·g。

若 Σ_i w_i + (n−1)·g > L，则不可行；否则
τ(π) = max{ 0, max_{i<j} (q_i − q_j + S_{ij} − h_i − h_j)/2, max_k (a + D_k − q_k − h_k), max_k (q_k − h_k − (a + L − E_k)) }。

*证明.* 由引理 1，τ 可行当且仅当存在 z 满足 (D)(C) 且 |z_k − q_k| ≤ τ + h_k，也就是 z_k ∈ [ℓ_k(τ), r_k(τ)]，其中
ℓ_k = max(a + w_k/2, q_k − τ − h_k)，r_k = min(a + L − w_k/2, q_k + τ + h_k)。

由引理 2，可行当且仅当对所有 i ≤ j 有 ℓ_i + S_{ij} ≤ r_j。左边 max 与右边 min 各有两项，展开得四组不等式：

1. q_i − τ − h_i + S_{ij} ≤ q_j + τ + h_j，即 τ ≥ (q_i − q_j + S_{ij} − h_i − h_j)/2。i = j 时恒成立。
2. q_i − τ − h_i + S_{ij} ≤ a + L − w_j/2。由于 S_{ij} + w_j/2 随 j 递增（相邻差为 w_{j+1} + g ≥ 0），最紧的是 j = n，此时 S_{in} + w_n/2 = E_i，得 τ ≥ q_i − h_i − (a + L − E_i)。
3. a + w_i/2 + S_{ij} ≤ q_j + τ + h_j。由于 w_i/2 + S_{ij} 随 i 递减（i → i+1 时减少 w_i + g），最紧的是 i = 1，此时 w_1/2 + S_{1j} = D_j，得 τ ≥ a + D_j − q_j − h_j。
4. a + w_i/2 + S_{ij} ≤ a + L − w_j/2：与 τ 无关，最紧的情形即容量条件。

所有涉及 τ 的约束都是 τ ≥ 常数的形式，所以最小可行 τ 等于这些常数与 0 的最大值。□

## 2 层次约束

**引理 3（合法叶序的刻画）。** π ∈ Π(T)，当且仅当 π 可以通过"在每个结点处任意排列其孩子的叶块，再递归展开"得到。因此 |Π(T)| = ∏_v deg(v)!，乘积取遍分支结点。

*证明.* 对树高做归纳。
- (⇐) 递归展开时，每个孩子的叶块是连续的，所以每个结点的叶集都连续。
- (⇒) 若 π 使所有 S_v 连续，则根的每个孩子的叶集在 π 中各占一个连续块，这些块互不相交且覆盖全部叶子，因此 π 是这些块的某种排列；对每个块递归应用归纳假设即可。□

**命题 2（精确性）。** τ\*(T) = min_{π ∈ Π(T)} τ(π) 可以达到。若存在可行布局，则 τ\*(T) 是模型约束下最大参考偏差的精确最小值。

*证明.* Π(T) 有限。对每个 π，τ(π) 是一个下有界、可行的 LP 的最优值，因此可以达到（也可由命题 1 直接写出）。有限个可达最小值再取最小，仍然可达。□

**命题 3（展平的单调性与分解）。** 记 flatten(T, V) 为删除非根结点集合 V、并把其孩子并入最近的未删除祖先所得的树。则：
- (i) V ⊆ V' 蕴含 Π(flatten(T, V)) ⊆ Π(flatten(T, V'))，因而 τ\*(flatten(T, V')) ≤ τ\*(flatten(T, V))；
- (ii) 删除全部非根结点后得到星形树，Π 等于 S_n，τ\* 等于 τ_free；
- (iii) 层次代价 H := τ\*(T) − τ_free ≥ 0。

*证明.*
(i) flatten(T, V') 的结点集合是 flatten(T, V) 结点集合的子集，且保留下来的结点叶集不变；使更多叶集连续的叶序，当然也使其中一部分叶集连续。可行集变大，最优值不增。
(ii) 星形树只有根这一个约束，而根的叶集总是连续的。
(iii) 由 (i) 与 (ii) 直接得到。□

**命题 4（见证三元组下界）。** 若结点 v、叶子 i, j ∈ S_v、k ∉ S_v 满足 q_i < q_k < q_j，则
τ\*(T) ≥ min(q_k − q_i, q_j − q_k)/2。
因此 τ\*(T) ≥ max 取遍所有这样的三元组。

*证明.* 设 π ∈ Π(T)。S_v 在 π 中连续，k 不属于 S_v，所以 k 要么排在 i、j 两者之前，要么排在两者之后。由 (D)(C)(E)，anchor 的顺序与 π 一致：若 x 排在 y 之前，则 u_x ≤ z_x + w_x/2 < z_y − w_y/2 ≤ u_y。

- 若 k 在 i 之前，则 u_k ≤ u_i。于是 (q_k − u_k) + (u_i − q_i) ≥ q_k − q_i，从而 max(|u_k − q_k|, |u_i − q_i|) ≥ (q_k − q_i)/2。
- 若 k 在 j 之后，同理得下界 (q_j − q_k)/2。

两种情况下 τ(π) 都至少是两者中的较小值。对所有 π 取最小即得。□

**说明**：命题 4 给出一个**可解释的见证**，即"哪三个特征造成了冲突"，可以直接在图中标出。

## 3 显示分辨率下的精确多项式算法

**离散模型。** 像素宽度为 δ，画布共 N 个像素。
- 宽度与间距为整数像素：W_i、G。
- 叶子 i 占据像素 [s_i, s_i + W_i)，中心为 z_i = s_i + W_i/2。
- 分离约束：沿 π 相邻的 x、y 满足 s_y ≥ s_x + W_x + G。
- 画布约束：0 ≤ s_i ≤ N − W_i。
- 由引理 1，偏差 ≤ τ 当且仅当 s_i ∈ [lo_i(τ), hi_i(τ)]，其中
  lo_i = max(0, ⌈q_i − τ − h_i − W_i/2⌉)，hi_i = min(N − W_i, ⌊q_i + τ + h_i − W_i/2⌋)。

**定义.** 对子树 S 与整数 x，令 E_S(x) 为：在"S 的所有叶子起点都不早于 x、S 的叶序属于 Π(S)、窗口约束满足"的条件下，**S 之后下一个叶子的最早可用起点**，即最后一个叶子的 s + W + G 的最小值。若不可行，则 E_S(x) = ∞。

**引理 4（最早结束原则）。** 对固定叶序与起点下界 x，贪心放置 s_1 = max(x, lo_1)、s_{k+1} = max(s_k + W_k + G, lo_{k+1}) 可行当且仅当存在可行放置；并且它使每个 s_k 都取到所有可行放置中的最小值。

*证明.* 对 k 归纳。任何可行放置都满足 s_1 ≥ max(x, lo_1)，以及 s_{k+1} ≥ s_k + W_k + G ≥（归纳假设下的贪心 s_k）+ W_k + G，同时 s_{k+1} ≥ lo_{k+1}。因此每个位置上贪心值最小。若贪心在某处超过 hi，则任何放置在该处也超过 hi，因而不可行。□

**定理 1（精确 DP）。** 对叶子 i，E_i(x) = s + W_i + G，其中 s = max(x, lo_i)；若 s > hi_i 则为 ∞。

对有 m 个孩子 C_1, …, C_m 的结点 S：
E_S = min over 孩子的排列 σ of E_{C_σ(m)} ∘ ⋯ ∘ E_{C_σ(1)}。

- m = 2 时：E_S = min(E_B ∘ E_A, E_A ∘ E_B)。
- 一般 m 用子集动态规划：F_∅ = id，F_M = min_{c ∈ M} E_c ∘ F_{M \ {c}}，E_S = F_{全集}。

τ 可行当且仅当 E_root(0) < ∞。E_S 对 x 单调不减，可行性对 τ 单调，所以对 τ 二分即可得到 τ\*_disc，精确到二分容差，而不是符号意义上的精确值。

**复杂度**：每个函数存成长度约为 N 的数组，复合运算为 O(N)。
- 二叉树一次可行性判定需 O(n·N)，总计 O(n·N·log(N/ε))；这是关于分辨率 N 的**伪多项式**；
- m 叉结点需 O(2^m·m·N)，对度数是指数级的。

**适用范围**：可扩展的 DP 计算的是**证书**；完整布局流程中，在预算内选叶序的二次规划仍需枚举候选叶序。

*证明.*
1. **单调性**：由引理 4，E_S(x) 是在一个随 x 增大而收缩的可行集上的最小值，所以单调不减。复合与逐点最小值都保持单调性。
2. **正确性**（对树高归纳）：S 的合法叶序就是"孩子块的某个排列 + 各孩子内部的合法叶序"（引理 3）。对固定的孩子排列，由引理 4，前面块的最早结束值是后面块唯一需要的信息：后面块的约束只依赖于其起点下界，而下界越小可行性越好（单调性）。因此逐块复合各孩子的最优 E 函数，得到该排列下的最优值；再对所有排列取最小，即得 E_S。
3. 根处 E_root(0) < ∞ 当且仅当存在可行布局。
4. 可行性对 τ 单调：窗口随 τ 增大而扩大。□

**命题 5（离散化误差）。** 若宽度与间距是 δ 的整数倍，且画布与像素网格对齐，则
0 ≤ τ\*_disc − τ\*_cont ≤ δ/2。

*证明.*
- 下界：离散可行解也是连续可行解。
- 上界：取连续最优解，把每个起点用 ⌊x + 1/2⌋ 取整到整数像素（这种取整是平移等变的，不能用"就近取偶"）。它是单调的，且对整数 d 有 ⌊x + d + 1/2⌋ = ⌊x + 1/2⌋ + d，所以整数分离约束与画布约束都保持；每个中心最多移动 1/2 像素，偏差最多增加 δ/2。□

**命题 5′（严格下界）.** 对一般的实数宽度与间距，令放松离散问题为：宽度与间距向下取整为 ⌊w_i/δ⌋、⌊g/δ⌋，偏心半径仍取原值 h_i。则
τ\*_cont ≥ τ\*_disc,relax − δ/2。

*证明.*
1. 原问题的任何可行布局，对放松后的连续问题也可行：宽度与间距变小使分离与画布约束放宽，偏心约束不变。所以 τ\*_relax ≤ τ\*_cont。
2. 放松问题满足命题 5 的条件，所以 τ\*_disc,relax ≤ τ\*_relax + δ/2。
3. 两式合并即得。□

位置–拓扑下界曲线（推论 1）的数值计算采用命题 5′ 的下界，再减去二分容差，所以画出的曲线是连续问题的**严格**下界。

**【数值核对】**
- 300 个随机层次（单位宽度，以及可变宽度 / 间距 / 偏心）上，DP 与暴力枚举的最大差为 0.495 像素，符合命题 5；
- ERA5 与 Ring 的全部 158 帧上，差值在 0.6 像素以内（其中部分宽度不是整数像素，四舍五入带来少量额外误差），每帧耗时 2 ms；
- 在 4096 个叶子、16384 个像素的随机层次上，精确求解用时 4.0 s。

## 4 拓扑失真与根本权衡

设一维图为画布上的函数 g（任意填充方法均可），叶子 i 的 anchor 位于 a_i。对 join tree 定义
- 一维合并层级 m_g(i, j) := max_{x ∈ [a_i, a_j]} g(x)；
- 真实合并层级 m_T(i, j) := f(lca_T(i, j))；
- **拓扑失真** d_top := max_{i≠j} |m_g(i, j) − m_T(i, j)|。

**引理 5（一维合并层级）。** 若 a_i、a_j 是 g 的两个局部极小，则它们在 g 的下水平集中连通的最小等值恰为 m_g(i, j)。

*证明.* 在直线上，下水平集 {g ≤ α} 的连通分量是区间。a_i、a_j 位于同一分量，当且仅当整个 [a_i, a_j] ⊆ {g ≤ α}，也就是 α ≥ max_{[a_i, a_j]} g。□

**命题 6（与交错距离等价）。** 若 g 的极小值恰好就是这 n 个带标签的叶子，且 g(a_i) = f(i)，则 d_top 等于 T 与 g 的合并树（两者带相同标签）的 ℓ∞-cophenetic 距离。由 Munch 与 Stefanou [27]，这个距离等于带标签交错距离。

*证明.* 由引理 5，m_g(i, j) 就是 g 的合并树中 lca(i, j) 的高度，也就是 cophenetic 向量的 (i, j) 分量。对角分量（叶高）两者相等，所以 ℓ∞ 距离等于非对角分量差的最大值，即 d_top。再引用 [27] 的定理即得。□

**约定**（GPT 评审已核对原文）：[27] 的定义 3.7 使用**到叶子的双射标签**，推论 4.3 的 cophenetic 向量包含对角的叶高分量。我们需要：两棵树的叶标签相同且为双射；叶高相等；g 没有额外的出生极值；根按标准方式向上延伸。在这些条件下得到的是带标签（系统发育树意义下）的交错距离，而不是不带标签的交错距离。

**【数值核对】** 在 ERA5 全部 51 个放松帧上，渲染后一维列的极小值个数都等于原树叶子数，没有伪极值，前提成立。

**定理 2（非连续性的拓扑代价）。** 设在一维图的叶序中，非根结点 v 的叶集 S_v 不连续，即存在 i, j ∈ S_v 与 k ∉ S_v，使 a_k 位于 a_i 与 a_j 之间。则**对任何填充 g**，都有
d_top ≥ γ_v / 2，其中 γ_v := f(p(v)) − f(v) 是 v 与其父结点的合并值之差。

*证明.*
1. 因为 [a_i, a_k] ⊆ [a_i, a_j]，所以 m_g(i, k) ≤ m_g(i, j)。
2. 在 T 中，lca(i, j) 位于 v 的子树内，所以 m_T(i, j) ≤ f(v)；k ∉ S_v，所以 lca(i, k) 是 v 的真祖先，从而 m_T(i, k) ≥ f(p(v))。
3. 于是
   γ_v ≤ m_T(i, k) − m_T(i, j)
   = [m_T(i, k) − m_g(i, k)] + [m_g(i, k) − m_g(i, j)] + [m_g(i, j) − m_T(i, j)]
   ≤ d_top + 0 + d_top。□

**说明（紧性）.** 1/2 在一般情况下不能再改进。以三叶为例，令 i 与 k 之间的最大值和 k 与 j 之间的最大值都等于 f(v) + γ_v/2，则所有叶对的误差恰为 γ_v/2。本文采用的 LCA 填充在被打破处给出完整的 γ_v。

**说明.** 定理 2 **不需要**"anchor 是极值"的假设：它只用到"一维合并层级 = 区间最大值"这一定义。只有把 d_top 解释为交错距离时，才需要命题 6 的条件。γ_v 是相邻合并值之差，一般**不等于**通常意义（出生–死亡）上的持久性。

**【数值核对】** 在 5 个数据集 × 8 个放松上限下，共 783 个"存在被打破结点"的帧中，定理 2 的违反次数为 **0**。实测 d_top 与被打破结点最大 γ 之比：中位数为 1.00，最大为 2.36（山火），也就是最高达到定理下界 γ/2 的约 4.7 倍。本文的 LCA 填充**没有**常数倍的近似保证。

**推论 1（位置–拓扑下界曲线）.** 定义
Φ_T(δ) := τ\*(flatten(T, {v 非根 : γ_v ≤ 2δ}))。

则对任何满足 (D)(C)(E) 的布局与任何填充，都有
max_i |u_i − q_i| ≥ Φ_T(d_top)。

即：没有任何一维图能同时让位置误差低于 Φ_T(δ)、拓扑失真不超过 δ。

注意：推论 1 是**必要**下界。它一般**不可达**，因为定理 2 的 1/2 不一定能对所有结点同时取到；它也不给任何具体算法提供近似保证。

*证明.*
1. 令 V 为叶序中被打破的结点集合。由定理 2，每个 v ∈ V 满足 γ_v ≤ 2·d_top，所以 V ⊆ W := {v : γ_v ≤ 2·d_top}。
2. 所有不在 V 中的结点都连续，由引理 3，叶序 π ∈ Π(flatten(T, V)) ⊆ Π(flatten(T, W))（命题 3(i)）。
3. 因此 max_i |u_i − q_i| ≥ τ(π) ≥ τ\*(flatten(T, W)) = Φ_T(d_top)。□

**【数值核对】** 在 5 个数据集上，所有实测点都位于下界曲线之上（`prototypes/output/frontier.json`、`frontier.png`）。
