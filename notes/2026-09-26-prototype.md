## 结果 1：Ring，参考 = 到环心的径向距离 ✅

图：`prototypes/output/ring_task_reference.png`

- **一张图就能读出"环在扩张"**：anchor 沿解析半径 r(t) 单调上升。anchor 与解析半径的平均绝对误差为 6.7。网格间距是 16.2，所以这个误差主要来自极值点落在离散网格上。
- 世界 X 参考图、TMTM、ST-MTM 都看不出"半径随时间增长"这一事实。
- **证书的含义得到验证**：
  - 前 8 帧 τ\* ≈ 18，但去掉层次约束后的 τ\* 也是 18。所以这部分偏差不来自层次，而来自"单个大特征的宽度必须放进画布"。r≈0 时，宽 105 的区间放不到原点附近。
  - 后续帧的层次代价最大只有 4.9，出现在 20 帧里。
  - "有层次 vs 无层次"两个 τ\* 之差，正是查新复核建议的消融：它能把偏差归因到层次还是宽度/画布上。
- 担心的拥挤问题并不严重：环上的多个极大值 q 都接近 r，被宽度撑开大约 ±10，整条带仍然贴着 r(t)。

## 结果 2：三高斯（复刻 ST-MTM 的动机场景），参考 = 到焦点 l1 的距离 ⚠️ 发现关键失效模式

图：`prototypes/output/gaussians_task_reference.png`

场景：l1、l2 静止，并由一条脊连接，所以在合并树中先合并；l3 从 l2 附近出发，移动到与 l1、l2 等距的位置。d(l2,l1)=85；d(l3,l1) 从 97 降到 51，在 **t=13** 时小于 85。

- **t < 13**：l3 的 anchor 与真实距离几乎重合，图上能直接读出"l3 正在靠近 l1"，而且带单位。
- **t ≥ 13**：参考值给出的顺序是 l1 < l3 < l2，但合并树要求 (l1, l2) 相邻，这个顺序不合法。求解器只能取最小最大折中：l3 被压在 l2 外侧，**l2 的 anchor 被拉着一起向 l1 移动**，两者都偏离约 17 = (85−51)/2。
- 结果是：**图给出了"l2 也在靠近 l1"的错误印象**。这正是 ST-MTM 批评 TMTM 的那种错误。
- **但证书把这个问题暴露了出来**：
  - τ\*（有层次）从 t≈12 开始上升到 18.4；
  - τ\*（无层次）始终约为 0.3；
  - 层次代价第一次超过 1 是在 t=15，与几何上的交叉时刻 t=13 吻合。
  - 也就是说，τ\* 准确指出了"何时、因为什么"这张图不可信。
- 世界 X 参考图在末段也有同样的冲突（l1 < l3 < l2 在 X 方向同样不合法）；ST-MTM 同样无法把 l3 放到 l1 和 l2 之间。**这是所有保层次的一维布局共同的限制，不是我们独有的问题**。区别在于只有我们能量化它。

## 这对研究方向意味着什么

1. **方向 1 成立**：任务参考让一张图承载带单位的任务量，Ring 的效果非常直观。
2. **证书是真正的卖点**：τ\* 以及"有层次 vs 无层次"的分解，可以精确、可验证地回答"这张图哪里在说谎、为什么说谎"。这把查新中偏弱的 C3（可视化偏差）变成了有实质内容的贡献。
3. **新出现的研究问题**（可能是论文的核心）：**参考坐标与合并树层次冲突时，图应该怎么办？**
   - (a) 现在的做法：最小最大折中，会误导读者；
   - (b) 优先保护关键特征：例如固定焦点或用户选中的特征，把偏差分摊到其他特征上（加权最小最大）；
   - (c) 在冲突区间显式标出"真实位置"，比如用幽灵标记或误差须线；
   - (d) 在冲突时允许局部破坏层次，并在图上标注出来。
   - 需要比较这几种策略，并做读者实验。
4. **待解决**：
   - 合成场景出现了额外的小极大值：t≥45 时是 4 个叶子，是真实存在的局部极大值，需要简化阈值；
   - 图面设计还很粗糙（线叠在标量图上）；
   - 还没有在 ERA5 上验证；
   - 还没有用户实验。
