# 补充材料方案（2026-09-27，草案，待讨论）

## 官方要求（PacificVis 2027 投稿指南，已核实原文）

- **鼓励提交**：视频、代码、数据集、评估细节、额外的图；尽量包含算法设置和数据集。
- **截稿后不能再改**：要提交稳定的材料。
- **正文必须能独立读懂**：审稿人**不一定**看补充材料。
  - 所以正文里的每个结论都要有自己的依据；补充材料只负责"更完整、可验证"。
- **补充材料和论文一起接受审稿**：录用后会随论文收录进 IEEE Xplore。
- **可选双盲或单盲**：我们现在按双盲准备，所以补充材料也必须匿名。
- **本届会议论文轨道主席**：Yong Wang（NTU）、**Bei Wang（Utah）**、Giuseppe Liotta（Perugia）。
  - Bei Wang 是交错距离方向的作者，我们引用了她的工作。
  - Liotta 是图绘制方向的专家。
  - 所以理论部分和算法部分都可能被非常懂行的人审。

## 设计原则

1. **一一对应**：正文的每个定理、表格和数字，都能在补充材料里找到完整证明、完整数据或复现脚本。
2. **编号对齐**：补充文档各节 S1–S9 与正文章节对应；正文在需要处写"见 Supplement S3.2"。
3. **可复现**：每个数字都能通过一条命令从原始数据重新算出（`paper_numbers.py` 负责逐条核对）。
4. **诚实**：正文放不下的反例、负面结果、失败的设定，都在补充材料里完整给出。

### M2. 代码与数据包（匿名 zip 或匿名仓库）——强烈建议

- **代码**：
  - `prototypes/`（全部实验与作图脚本）；
  - 合作者的 `src/ramtm/`（参考锚定布局、TMTM / ST-MTM 实现）。
- **一键复现**：`make all` 或逐条命令，生成所有表格和图。
- **数据**：
  - 处理后的特征数据（合并树、轨迹、面积、参考坐标，JSON 格式，较小）；
  - 原始 ERA5 和山火数据只提供下载脚本和校验值（体积、许可证考虑）。
- **README**：对应论文的每张图和每个表。

可以用现有图，加少量动画或屏幕录制完成。

一个网页，可以拖动 κ，实时看位置误差和拓扑代价的变化。做好需要时间；如果时间允许，可放进补充材料。

## 需要讨论并做决定的问题

1. **匿名性风险（最重要）**
   - 合作者的 GitHub 仓库 `lelewang1109/RA-MTM` 是**公开**的，里面有参考锚定布局的代码和文档，而且带作者名。
   - 双盲评审时，审稿人可能搜到它，从而识别出作者。
   - 可选做法：
     - (a) 投稿期间把仓库设为私有；
     - (b) 改成单盲（指南允许，"若匿名会妨碍科学表达"）；
     - (c) 保持现状、接受风险。
   - 建议 (a)，需要合作者同意。
2. **合作者代码是否放进补充材料**：需要合作者同意，并决定许可证。
3. **托管方式**：
   - 直接上传到 PCS（最稳妥，截稿后固定不变）；
   - 或者用匿名仓库（如 anonymous.4open.science），但必须保证截稿后不再改动。
4. **原始数据是否再分发**：
   - ERA5 在哥白尼许可下允许注明来源后再分发；
   - 山火数据是 CC BY 4.0，也可以；
   - 但体积较大，建议提供脚本和校验值即可。
5. **是否做视频**：建议做，大约需要 1–2 天。
6. **正文与补充材料的引用**：定稿时在正文相应位置加"见补充材料 Sx"，并在补充材料中写明"本节对应正文第几节"。
