# 论文定位与写作计划（草案，2026-09-26）

- 目标：PacificVis 2027 Conference Paper Track。摘要 11/2，全文 11/9，正文 9 页 + 2 页参考文献。
- 状态：**待与合作者对齐**。

## 1. 定位：不是纯理论证明，而是"可证明的方法 + 实证刻画"

- 不宜写成"证明一维时空图存在根本权衡"这种纯理论文章：
  - 一般性的不可能定理很容易举例证明（三个特征、一个子树），但太平凡；
  - 更强的一般定理，6 周内做不出来。
- 能写成、而且站得住的形式是一篇**技术论文**，核心是一个**可证明最优的证书**，外加对真实数据的**实证刻画**：
  - "证明"的部分：τ\* 是在给定约束下**可证明的精确下界**（最优性命题），而且可以按原因分解（层次 vs 空间）；
  - "发现"的部分：用这个证书和受控放松测量真实数据，得到"冲突普遍存在，而且来自强合并"；
  - "方法"的部分：单图、自动方向、证书披露、可控放松，默认不需要按数据集设参数。

这样的转向在形式上仍是方法论文（PacificVis 的主流），但回答的问题变了：

> **旧问题**：怎样布局更好？（又一个布局方法，要和 ST-MTM 拼指标）
> **新问题**：保合并树的一维时空图，**最多能有多忠实于空间位置**？不忠实的部分能否被证明、定位和控制？

**连续性**：合作者现有的两阶段 LP/QP 里，第一阶段的 LP 正是证书的来源。新定位把他最有新意的部分提升为主角，X/Y 双轴则降为特例。

## 2. 创新点（投稿时的 contribution 列表）

1. **忠实度模型**：把合并树时空图统一建模为"满足层次约束的一维区间布局"，并区分三种忠实度：拓扑（合并树恒等）、位置（沿参考坐标）、大小（绝对测度）。TMTM、ST-MTM、RA-MTM 分别对应这个空间里的不同取舍点。
2. **偏差证书（核心技术贡献）**：
   - 对每一帧，计算任何保持子树连续、宽度与测度成正比的布局，其最大参考偏差的**精确下界 τ\***；
   - 固定叶序时有闭式解（已与 LP 验证，误差 1e-14）；
   - 把 τ\* 分解为层次代价 τ_hier − τ_free 与空间代价；
   - 差异：Li & Wang 2019 解决的是无层次约束的情形（论文里必须引用），层次约束版本以及在可视化中的用途，查新中没有发现先例。
3. **受控的位置–拓扑权衡**：
   - 由证书触发、按合并持久性从弱到强的局部放松；
   - 在渲染后的图上精确测量合并层级失真；
   - 由此得到每个数据集的权衡曲线；
   - 默认保持拓扑并披露偏差；放松作为用户显式控制的滑块。
4. **实证发现**（适用于整个方法族）：在 ERA5 上，58% 的帧存在超过可辨阈值的冲突（最大达到轴长的 31%）；把位置误差减半，需要约 28 hPa 的合并失真，而 Ring 上的冲突则很便宜。由此给出设计建议。
5. （实用层面）默认不需要按数据集设参数：自动选取捕获运动最多的方向（与坐标系摆放无关），加上按画布比例的统一常数。

**明确不声称**：新的填充算法；在所有指标上全面优于 ST-MTM；超出模型范围的一般不可能定理；用户实验结论。

一句话定位（草案）：
> We make the geometric fidelity of merge-tree-based static maps *certifiable*: for every time step we compute the minimum reference error any hierarchy-preserving layout must incur, attribute it to hierarchy or space, and let analysts trade topology for position in a measured, controlled way — revealing that on real weather data this trade-off is pervasive and expensive.

标题候选：
- *How Faithful Can a Merge Tree Map Be? Certified Position–Topology Trade-offs in Static Visualizations of Time-Varying Scalar Fields*
- *Certified Merge Tree Maps*

## 3. 这类论文怎么写（结构与页面预算，共 9 页）

| 节 | 内容 | 页 |
|---|---|---|
| 1 引言 | 用 ERA5 例子提出问题：静态图把二维压成一维，已有方法都在优化某个东西，但没人告诉读者图有多失真 → 研究问题 → 贡献列表 → 预告主要发现 | 1.0 |
| 2 相关工作 | 合并树与拓扑可视化；一维投影与时空摘要（MotionRugs、Franke 等）；失真可视化；区间布局算法（Li & Wang） | 0.75 |
| 3 背景 | 增广合并树；TMTM / ST-MTM 流程 | 0.5 |
| 4 忠实度模型 | 三种忠实度的形式化定义；已有方法在模型中的位置；三叶小例子说明冲突 | 1.0 |
| 5 证书 | 命题 1：τ\* 最优（证明）；命题 2：固定叶序的闭式解；命题 3：层次 / 空间分解；算法与复杂度 | 1.25 |
| 6 利用权衡 | 自动参考方向；证书驱动的放松；合并失真度量；渲染与披露编码（聚合式） | 1.25 |
| 7 评估 | 数据集；问题 1：冲突有多普遍；问题 2：权衡曲线；问题 3：与 TMTM / ST-MTM / 固定 X 的对比；稳健性（θ、方向、时间步）；运行时间；ERA5 案例（Lothar / Martin） | 2.5 |
| 8 讨论 | 对方法族的启示；限制（贪心、小树枚举、无用户实验） | 0.5 |
| 9 结论 | | 0.25 |

写作原则：
- **每条贡献都要对应一节，每个结论都要对应一张图或一张表**。评估按研究问题组织，而不是按数据集组织。
- **先写方法和评估，最后写引言**。引言的主要发现要用具体数字。
- 把负面结果写成边界。例如"冲突普遍存在"本身就是一个发现；另外说明哪些东西不能推广（自动选径向中心、稳定性优先），只需一句话，避免审稿人追问。
- 第一张图（teaser）要一眼讲清故事：同一段 ERA5，左边是现有方法（没有任何失真提示），右边是我们的图加证书强度带，再插入一条权衡曲线。

计划中的图：teaser；流程图；三叶冲突小例子；证书分解示意；三个数据集的权衡曲线；ERA5 案例；稳健性小图；运行时间表。
