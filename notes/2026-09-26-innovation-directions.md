# 创新方向推敲（2026-09-26）

依据：两篇论文全文（`references/pdf/koepp22.pdf` = TMTM，`ssrn-6604235.pdf` = ST-MTM 预印本）、合作者仓库 `38a5088`、一轮相关工作检索。**尚未做系统查新**，下文的"新颖性"判断都是初步的。

## 1. 三种方法各自让 1D 纵轴"承载"什么

| | 纵轴承载的不变量 | 丢掉的 |
|---|---|---|
| TMTM | 拓扑（Merge Tree Identity）+ 全部样本的数据上下文 | 几何：位置、距离都没有意义 |
| ST-MTM | 叶质心之间的**相对**距离（stress）+ 顺序一致性 | 绝对位置；宽度只是总量 K 的份额；纵轴没有单位 |
| RA-MTM | 沿固定方向的**绝对**坐标 + 绝对宽度 + 最小偏移证书 τ* | 相对二维距离（Ring 距离误差 0.51，ST-MTM 为 0.28） |

这条脉络的本质是：**1D 纵轴上保留哪一种几何量**。RA-MTM 真正迈出的一步，是让纵轴第一次**有单位、可读数**。这一点与"X/Y"本身无关。

## 2. 为什么说 X/Y 双轴的思路有问题

### 2.1 "固定轴 × 时间"就是 Hovmöller 图

气象学自 1949 年起就用 Hovmöller 图（经度–时间、纬度–时间）。RA-MTM 的 X 图相当于"保拓扑的经度–时间 Hovmöller 图"，双轴版本就是一对经度–时间 + 纬度–时间图，这在气象分析中是常规做法。懂气候或科学可视化的审稿人一眼就会看出来。

所以"双轴"本身不能作为贡献。真正的新东西只有两点：保持拓扑和全部数据上下文，以及带证书的参考偏移。

### 2.2 投影到某个轴、用额外通道补回二维，这两件事在运动数据可视化里都有先例

- MotionRugs（Buchmüller et al., TVCG 2019）把每个时刻压成 1D 排序。
- Stable Principal Components（Wulms et al.）改为投影到平滑变化的主方向上。
- SpatialRugs（C&G 2021）用颜色编码二维位置。
- MoReVis（TVCG 2023）用布局优化让标记的大小和位置接近原始空间里的数值。

区别在于：它们处理的是轨迹或区域，不是标量场，也不保持拓扑和数据上下文。

### 2.3 两张图没有带来可感知的好处

- 二维读出靠程序按 track ID 配对，但地图上刻意没有画 ID。读者无法把 X 图里的一条带和 Y 图里的一条带对应起来。`position_2d_nrmse` 衡量的是"算法能解码多少"，不是"人能看出多少"。
- 真正能读出二维位置的是 `longest_tracks.png`，而它就是普通的 x(t)、y(t) 折线图。审稿人会问：那为什么不直接画轨迹？
- 同一棵树、同一套填充画了两遍，占用双倍空间还分散注意力。它放弃了这一类方法最核心的卖点：**一张图**。
- 固定 X/Y 本身也不对：换个坐标方向，结果就变了。Ring 是径向对称的，X、Y 都不是有意义的坐标，**半径**才是。

结论：同意你的判断。双轴不宜作为主线。

## 3. RA-MTM 里值得保留的东西

1. **参考锚定**：纵轴有明确的含义和单位，能读数。
2. **两阶段 LP/QP 与 τ\* 证书**：在层次、宽度、间距、画布约束下，给出不可避免偏移的下界。两篇前作都没有任何"保证"。
3. **绝对宽度 w = cA**：跨帧可以比较大小。
4. **运动残差项**：惩罚"动得不对"，而不是"动了"。

以上都和"选 X 还是 Y"无关。代码层面，`error_budget.py::solve_frame` 已经支持直接传入每个叶子的一维参考值 `reference`（第 109 行），换参考函数不需要改求解器。

## 4. 候选方向（按推荐程度）

### 方向 1（核心推荐）：由任务决定的参考坐标，一张图

把 q_i = a·R_i 推广为 q_i = φ(R_i, t)，φ 是由分析任务选定的任意标量"参考函数"。可选的 φ 包括：

- 方向投影：经度、纬度，或自动估计的主运动方向。X/Y 退化为其中的特例。
- **到中心的径向距离**：Ring 扩张会表现为一条单调上移的带，预计是一张很有说服力的图。
- **沿路径的测地距离**：沿风暴路径、河道、海岸线、船体尾流。
- **到焦点特征的距离**（以某个特征为中心的视角）：例如每个低压到 Lothar 的距离。这能直接读出"接近/远离"。ST-MTM 的动机例子（图 2：l3 靠近 l1）正是这类任务，而我们能给出带单位的绝对距离。

定位：**保拓扑、带偏移证书的广义 Hovmöller 图**。气象学里的径向–时间图、沿路径 Hovmöller 图，都要对另一个维度做平均，会抹掉特征。我们保留全部样本、层次结构，并给出偏移证书。这样一来，审稿人最可能提出的"这不就是 Hovmöller 图吗"反而成了论文的切入点。

**额外卖点——可比性**：纵轴有绝对单位，不同集合成员、不同时间窗、不同数据集的图可以直接对照。TMTM 和 ST-MTM 的纵轴是任意的，做不到这一点。

风险：
- 选 φ 增加了设计负担，需要提供默认值（例如主运动方向）。
- 需要查新：径向或沿路径的 Hovmöller 图已有先例，要确认拓扑结合的部分是新的。

### 方向 2（配套）："诚实"的地图：把偏移画出来

在同一张图里编码 τ(t) 和每个特征的偏移 |u − q|。例如从 anchor 到真实参考点画误差须线，或在图的上方加一条 τ 强度带。读者能看出哪里的纵轴可信。

相关工作：Rauscher et al.（arXiv 2604.25298，2026）用阴影线、光晕等方式可视化 1D 排序的邻域失真，但对象是地理多边形，不涉及拓扑和证书。这个方向可以作为论文中的一节，而不是独立论文。

### 方向 3（必需的技术支撑）：可扩展性 + 时间上的全局最优

- 目前的做法是枚举全部合法叶序，数量达到 2^(内部结点数)。Storms 有 15–79 个超结点，Cylinder 有 2–375 个（TMTM 表 1），枚举在这种规模下不可行。
  - 可行的替代：对 τ 做二分搜索，再用树上动态规划判断是否可行。这是带树形顺序约束的区间排布问题，有望做到多项式时间。
- 目前是逐帧因果求解。可以改成对每帧的候选叶序在时间轴上做 Viterbi 动态规划，把换序代价和 anchor 运动一起纳入，得到整条序列上的全局最优。
- 这一项不适合做标题贡献，但不做的话，审稿人会以可扩展性为由拒稿。

### 方向 4（可选）：在同一张图里补上第二个坐标

在 anchor 轨迹线上用第二个视觉通道（色相、方向小箭头等）表示另一个坐标或二维运动方向。

SpatialRugs 用颜色编码位置，但在标量图里颜色已经用来表示数值，只能改成叠加线或字形。这种设计的感知效果有风险，需要用户实验支撑。

## 5. 评价方式也要跟着改

- 不能只拿方法自己追踪的参考点当真值。要同时报告 SNS/TW，以及与所选任务直接相关的指标（例如"接近/远离"事件的判断正确率）。
