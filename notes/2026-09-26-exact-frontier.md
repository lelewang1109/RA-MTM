# 精确权衡曲线、最优画法与不依赖宽度的下界（2026-09-26 晚）

作者名单已确定（评审稿仍匿名）。本次补做 W2 的研究内容，新增三项理论结果和一张 teaser 图，已写进 `paper/pacificvis2027/main.tex` 与 `paper/proofs.tex`。

## 1. 最优画法（闭式解）

- **问题**：给定叶子的一维顺序，怎样画每一列的数值，才能让拓扑失真 d_top 最小？
- **结论**（命题 `prop:fill`）：任何画法都只取决于相邻锚点之间的"屏障高度" b_k。最优屏障为 b_k = C_k + δ\*，其中 C_k 是跨过第 k 个间隔的叶对里最小的合并值。最小失真有闭式：

  δ\*(π) = max{ 0, max_k (ℓ_k − C_k), max_{i<j} ½ (P_ij − max_{i≤k<j} C_k) }

  其中 ℓ_k 是相邻两个叶子的叶值取较大者。
- δ\*(π) = 0 当且仅当 π 保持层次。
- **新机制**：ℓ_k − C_k 这一项。一个较浅的低压夹在两个合并很深的低压之间时，这两个低压在一维图上的合并值至少被抬到这个浅低压自己的值，无论怎样画都一样。定理 2（γ/2）没有包含这一项。
- **实现验证**：`prototypes/filling.py` 把最优画法写进真实渲染的地图，实测 d_top 与闭式解相差不超过 1e-15；保持层次的帧拓扑仍然完全正确。
- **与现有画法比较**：原来沿 LCA 路径的画法，失真最多是最优值的 **2.0 倍**（五个数据集的实测最大值都正好是 2）。在 Ring 和 Gaussians 上，最优画法把失真减半。在气压数据的大预算下，浅低压那一项起主导，最优画法几乎省不了（ERA5 κ = 20%：27.85 → 27.78 hPa）。

## 2. 精确的位置–拓扑权衡曲线（定理 `thm:exact`）

- 位置误差只经由 τ(π) 依赖于顺序，拓扑失真只经由 δ\*(π) 依赖于顺序，而且两者可以同时取到。所以在所有一维地图中，可达的权衡曲线就是
  F(δ) = min{ τ(π) : δ\*(π) ≤ δ }。
- 所有帧的叶子数都不超过 11，因此逐帧枚举全部 n! 个顺序（`prototypes/attainable.py`）即可精确求出 F；ERA5 最慢的一帧约 3 分钟。
- **结果**：

| 数据集 | 在精确曲线上的帧（κ = 2%） | 其他预算下的最低比例 | 最大超出 | F − Φ 的均值 / 最大值（% 轴长） |
|---|---|---|---|---|
| ERA5 | 116/118 | 116/118 | 0.41% | 1.5 / 19 |
| ERA5-14 | 120/124 | 120/124 | 0.56% | 2.3 / 25 |
| 山火 | 29/30 | 27/30 | 0.67% | 0.9 / 11 |
| Ring | 39/40 | 39/40 | 0.14% | 0.4 / 5.8 |
| Gaussians | 64/64 | 64/64 | 0 | 0.3 / 2.8 |

- 合计 368/376（98%）的帧上，"阈值 + 剪枝"放松得到的顺序**恰好落在精确曲线上**（误差在半个像素以内）。这回答了评审提出的"与最优放松相比如何"。
- 汇总图（`fig_frontier_exact.png`）里，我们的点高于 F。原因是预算按合并差 γ 挑选结点，而真实代价 δ\* 还含有叶值那一项，所以各帧实际用到的预算小于全局预算。这是预算分配的问题，不是逐帧不够优。
- 可扩展的下界 Φ 与精确曲线 F 平均只差 0.3–2.3% 轴长；约三分之一的断点处在半个像素以内；个别帧最多差 25%。
- **τ_free 已精确求解**：原来 n > 6 时用爬山法求 τ_free，与全排列枚举的结果在所有帧上一致。冲突帧数不变（68/74/19/21/47），现在可以称为精确值。

## 3. 不依赖宽度模型的下界（命题 `prop:pt`）

- 去掉宽度、间距、偏心和画布，只保留顺序：τ_pt\* = 所有合法顺序中"最大逆序参考差的一半"的最小值。
- 它对**任何宽度模型、任何单调的坐标轴读法**都成立，因此能直接用于 TMTM 和 ST-MTM 的原生地图。这回答了评审提出的"基线用的是各自的宽度模型"。
- **结果**（`prototypes/pointcert.py`）：τ_pt\* > θ 的帧占 58% / 60% / 63% / 50% / 69%，与区间模型几乎一样，说明冲突不是宽度模型造成的。
- 按最好的单调读法换算后，TMTM 和 ST-MTM 平均偏离参考 24–29% 轴长，其中 6–8% 是任何保持合并树的顺序都无法避免的，其余部分是它们没有以位置为目标造成的。没有任何方法低于这个下界。
