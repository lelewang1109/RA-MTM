# Local data

This directory is intentionally excluded from Git. Experiment scripts create controlled datasets beneath `data/constructed/`.

The current local workspace may also contain large real-world datasets beneath `data/real/`. They are not required by the checked-in controlled experiments and must not be committed.

Expected local structure:

```text
data/
  constructed/          generated by the experiment scripts
    gaussian2d/         generated 2-D Gaussian inputs and extracted trees
  real/                 optional local-only source datasets
```
