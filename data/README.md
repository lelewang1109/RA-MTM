# Data layout

Data is intentionally excluded from Git. The code and experiment definitions are sufficient to regenerate all controlled inputs.

```text
data/
  generated/
    synthetic_1d/   inputs and extracted trees for the 1-D/polyline suite
    gaussian_2d/    scalar grids and extracted trees for the Gaussian suite
  real/             optional local source datasets, isolated from paper results
```

`data/generated/` may be safely regenerated by the corresponding experiment entry point. `data/real/` is never modified by the controlled pipelines.
