# 目录规范与整理记录

项目名称和仓库统一为 **RA-MTM**，Python 包为 `ramtm`。X/Y 表示方法内部两条参考轴，不再作为项目名前缀。

| 目录 | 职责 | 约定 |
|---|---|---|
| `src/ramtm/` | 算法、参考点、渲染与评价 | 使用标准 src 包布局；基线在 `baselines/` |
| `experiments/` | 数据集适配和固定实验协议 | `public.py` 共享驱动，`era5.py` 共享树/ERA5 工具，`ring/` 作者参数与数据生成 |
| `scripts/` | 用户运行入口 | `run_experiments.py` 运行，`verify_results.py` 审计 |
| `tests/` | 单元测试和回归数据 | 旧基线记录放 `fixtures/baselines/`，不是当前实验结果 |
| `docs/` | 研究说明 | 小写文件名，方法、求解、复现、结果分开 |
| `results/` | 当前已验证产物 | 只分 `ring/` 和 `era5/`，含基线、消融及完整证书 |
| `data/` | 输入数据及说明 | 不提交原始数据或本机链接 |
| `references/` | 来源记录 | 不提交论文 PDF |
