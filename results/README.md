# Results

This directory contains the inspectable outputs cited by the experiment report:

- `initial/`: controlled 1-D and polyline experiments, ablations, sensitivity analysis, and verification.
- `gaussian2d/`: controlled 2-D Gaussian-field figures, metrics, and topology checks.

Compact tables, JSON validation records, figures, SVGs, and the demonstration GIF are versioned. Large `.npz` numerical arrays are reproducible from the experiment scripts and are intentionally excluded from Git.
